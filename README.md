# Мои тренировки

Статическое приложение: HTML/CSS/JS, без сборки и зависимостей. Прогресс хранится в localStorage.

## Деплой на GitHub Pages
1. Создай репозиторий, загрузи содержимое этой папки в корень.
2. Settings → Pages → Source: «Deploy from a branch» → `main` / `(root)`.
3. Через минуту сайт откроется по `https://<логин>.github.io/<репозиторий>/`.
Vercel/Netlify: импортируй репозиторий, сборка не нужна.

## Фото и GIF
Положи файл в `img/` и допиши путь четвёртым полем строки упражнения в `js/data.js`:
`"Отжимания|подсказка||img/pushup.gif"`.
